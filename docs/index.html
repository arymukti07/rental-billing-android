Rental Billing Android

Interactive online preview for the Kotlin + Jetpack Compose rental billing app. Admin can manage devices, members, sessions, reports; members can monitor balance and rental history.

View GitHub Repo

What you can preview

This web page mirrors the app screens so the project can be reviewed online from any browser. The real Android source remains in Kotlin/Compose with Room, Hilt, PDF receipt, payment stub, and Firebase sync interface.

Offline-first databaseRoom entities for members, devices, sessions, and transactions.
Billing engine15-minute rounding, package pricing, overstay penalty, member discount.
Admin workflowRegister devices, top-up members, start/stop rentals, view daily report.
Member viewBalance, active rental bill, transaction history, and status.
